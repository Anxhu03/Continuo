Install the development build

"Continuo's Chrome Web Store release is currently being prepared."

Download Continuo Extension ZIP
Development Extension Setup: Continuo's Chrome Web Store release is currently being prepared. For now, you can install the development extension package manually in 6 simple steps.
STEP 01

Download Continuo

Download the Continuo extension package (.zip).

Download Continuo Extension continuo-extension.zip
STEP 02

Open Chrome Extensions

Open a new tab in Google Chrome, navigate to chrome://extensions in your address bar, and press Enter.

chrome://extensions
STEP 03

Enable Developer Mode

Turn on Developer mode using the toggle switch in the top-right corner of the Extensions page.

STEP 04

Extract Continuo

Extract the downloaded continuo-extension.zip file to a folder on your computer.

STEP 05

Load Continuo

Click Load unpacked and select the extracted Continuo extension folder.

STEP 06

Pin Continuo

Pin Continuo to your Chrome toolbar so it's always ready with one click during AI conversations.

You're ready.
